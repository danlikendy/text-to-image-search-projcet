Why it exists

A hosting catalog: user types a scene, you want the closest still. I do not fine-tune a joint embedding. Two off-the-shelf towers, L2 each, 2432 numbers into an MLP. The number I optimize is MAE against a blended expert/crowd score, not Instagram-pretty top-1.

Numbers I will defend

0.163val MAE (MLP-128)

Dummy MAE is 0.214. Ridge 0.197. Split is grouped by image so a photo cannot leak into val. Top-1 on 10 random test captions vs the labeled file: 0/10. The AUC is ranking quality on a pair; it is not “search works.”

Constraints

Captions that mention children never return a file. Train drops 288 images whose query_id captions hit the same regex. This page cannot run ResNet — GitHub Pages is static. Inference is local.
